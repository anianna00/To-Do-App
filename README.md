Aplikacja jest mobilnym menedżerem zadań (To-Do List).
W aplikacji zostały zawarte funkcje CRUD.

Autentykacja: Aplikacja wykorzystuje system Firebase do obsługi kont. Użytkownik przechodzi proces rejestracji, który wymaga weryfikacji adresu e-mail, co zwiększa bezpieczeństwo dostępu.

Główny ekran (Home): Centralne miejsce, gdzie użytkownik zarządza swoimi bieżącymi zadaniami. Pozwala na szybkie dodawanie nowych zadań do listy.

Zarządzanie zadaniami:

Dodawanie: Wpisywanie treści zadania w polu tekstowym i zatwierdzanie przyciskiem.

Edycja i usuwanie: Dłuższe przytrzymanie zadania na liście otwiera dedykowany ekran, który umożliwia zmianę treści zadania lub jego trwałe usunięcie.

Oznaczanie jako wykonane: Zadania ukończone są automatycznie przenoszone do zakładki „Completed”.

Nawigacja i Profil (Menu):

Home: Widok listy aktywnych zadań.

Completed: Archiwum wykonanych zadań.

User: Sekcja ustawień konta, pozwalająca na wylogowanie się, resetowanie hasła oraz usunięcie profilu użytkownika z bazy danych.

Użyte technologie:
Projekt jest aplikacją natywną na system Android.

Platforma: Android (Kotlin).

Baza danych i Autentykacja: Firebase Authentication i DAO
